The website should look like a modern developer command center rather than a traditional portfolio.

## Telegram contact form

The contact form sends messages to Telegram through a server function. Create a Telegram bot with BotFather, start a chat with the bot, and obtain the destination chat ID. Copy `.env.example` to `.env.local` and set `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID`. Keep the bot token private and configure the same variables as secrets in your deployment environment.
